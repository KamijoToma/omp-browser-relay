OMP Browser Relay (Background Fork)

Independent fork maintained by KamijoToma. This is not the bundled OMP extension. Based on the upstream oh-my-pi browser relay; original copyright notices are preserved in LICENSE.

The extension connects to a local omp-browser-relay process. The port and token must match its flags; Tailscale access below can be enabled or disabled live.

Agent pages open in a separate workspace window. You can observe and operate them at any time; focusing this window does not pause the agent. Drag a business tab into the workspace to grant control, or out to revoke it. Simultaneous actions on one page can conflict.

Chrome's mouse input can activate the workspace and interrupt typing or scrolling in another window. This shared-control policy permits that activation; it is not background focus isolation. The relay never selects, attaches, or directly controls tabs outside the workspace.

This is window isolation, not a sandbox: websites and scripts can still request popups or system dialogs. Global browser and native UI control is unsupported; the relay never focuses a window to recover.

Live Tailscale access

Remote CDP is unauthenticated. When enabled, only Tailscale IPv4 sources in 100.64.0.0/10 are served; this shared range is not a device identity. Restrict peers with Tailscale ACLs and host firewall rules. Changing access replaces the listening socket and disconnects active CDP clients; the local extension briefly reconnects.
