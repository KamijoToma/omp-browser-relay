OMP Browser Relay

The extension connects to a local omp-browser-relay process. Values here must match the flags the relay was started with.

Agent pages open in a separate background window, never in your normal browser window. Selecting an agent tab does not focus its window. Control pauses while you focus the agent window and resumes when you leave it. Dragging an agent tab into another window immediately releases it.

This is window isolation, not a sandbox: websites and scripts can still request popups or system dialogs. Global browser and native UI control is unsupported; the relay never focuses a window to recover.

Agent workspace

Older omp versions need an existing work page before connecting. Create one here without switching away from this window. Newer versions create their own work pages.
